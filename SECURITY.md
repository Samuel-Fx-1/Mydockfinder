# Security policy

## Scope

This repository contains PowerShell scripts and documentation for a Windows appearance setup kit. It does not contain MyDockFinder, its binaries, installers, config files, or Steam files. MyDockFinder has its own terms and support process.

The kit is not affiliated with the developer of MyDockFinder.

## Reporting a security problem

Please report a problem privately instead of posting exploit details in a public issue.

1. Open the repository's **Security** tab.
2. Use **Report a vulnerability** to open a private security advisory.
3. Include the affected script or document, the version or commit, the Windows version, and steps to reproduce.
4. Remove usernames, machine names, tokens, and other personal data from screenshots and logs before attaching them.

If private reporting is not available, open a public issue that says only that you need a private contact method. Do not include sensitive details in that issue.

## What to expect

The maintainer will acknowledge a report when possible, ask for missing details, and coordinate a fix before public disclosure. This is a volunteer project, so no fixed response time is promised.

## Out of scope

- Vulnerabilities in MyDockFinder itself. Report those to its developer.
- Problems caused by an unofficial copy, repack, cracked build, or modified config. Remove the unofficial copy and use the official Steam installation.
- Fonts, wallpapers, cursors, icons, or other assets obtained outside their official sources.

## Credentials

Never put passwords, access tokens, GitHub tokens, or other credentials in an issue, a script, a log, or a pull request. The kit does not need or store credentials.
